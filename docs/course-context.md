# Контекст курса: рабочий процесс на GitHub

Краткая выжимка модуля «Рабочий процесс на GitHub» программы «ИИ для разработчиков — Расширенный» (Хекслет).

## Подключение

- GitHub App `opencode-agent` устанавливается только на этот репозиторий.
- Workflow `.github/workflows/opencode.yml` срабатывает на `issue_comment` и `pull_request_review_comment` (`types: [created]`).
  Job запускается, только если в тексте есть `/oc` или `/opencode`.
- Права: `id-token: write`. Checkout с `persist-credentials: false`, затем `anomalyco/opencode/github@latest`.
- Модель задаётся как `провайдер/модель`, секрет зависит от провайдера. Для OpenCode Zen это `OPENCODE_API_KEY` и `opencode/<модель>`.
  Ключ нужен и для бесплатных моделей. Их список меняется, актуальный смотреть через `/models`.
- Workflow начинает работать только после мержа в основную ветку.
- Ошибки: «Bad credentials» значит, что имя секрета не совпадает с провайдером. «Resource not accessible by integration» значит, что не установлен App.
  «Permission denied» значит, что нет `id-token: write`.

## Сценарии

- **Issue:** `/oc explain` даёт разбор задачи. `/oc fix` создаёт ветку `opencode/…` и PR, связанный с issue.
- **Автотриаж:** событие `issues: opened`. Комментария нет, поэтому инструкция передаётся через `prompt`. Подходит дешёвая модель.
- **PR:** общий комментарий с `/oc` приходит как `issue_comment`, комментарий к строке приходит как `pull_request_review_comment`.
  Авторевью на `pull_request`, PR от `[bot]` пропускаются. Права только на чтение.
- **Расписание:** `schedule` (cron, UTC) плюс `workflow_dispatch` для отладки. `prompt` обязателен.
  Права задаются явно: `contents`, `pull-requests`, `issues: write`. Результат оформляется как issue или PR.

## Правила

- Агент не аппрувит и не мержит свои изменения, финальное решение за человеком.
- Ключи хранятся только в Secrets. Права минимальные, расширяются точечно.
- Нужна защита от зацикливания: события от ботов игнорируются.
- Дешёвая модель для триажа, сильная для ревью и аудита. Следить за расходами и лимитами.
